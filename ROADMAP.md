# Маршрут проекта «Полный зачёт»

Главный документ проекта: куда идём, в каком порядке и как привлекаем людей. Технические требования к боту — в `SPEC.md`, он не меняется от планов продвижения. Канал — в `docs/CHANNEL.md`, площадки для анонса — в `docs/PROMO_PLACES.md`, идеи на потом — в `IDEAS.md` (все в этом репозитории). Утилита «Радар» (разбор YouTube-роликов) — отдельный репозиторий `C:\dev\polny-zachet-radar` (`RADAR_SPEC.md`, `ABOUT.md`). Нарезка стримов — `C:\dev\shorts-cutter` (`SHORTS_CUTTER_PROMPT.md`).

Инструменты работы: Devin Desktop / Devin CLI (код, документы, поиск, сводки по запросу). Прежние инструменты Claude (чат проекта, Cowork, запланированные задачи) недоступны, подписки Claude нет. Правила работы Devin — в `AGENTS.md` каждого репозитория.

Ресурс: ~4 часа в день. Релиз GTA 6 — **19 ноября 2026** (PS5, Xbox Series X|S).

## Зачем проект

- Опыт запуска своего продукта: живые пользователи, статистика, продвижение.
- Небольшой дополнительный доход — приятная «копейка», не основной заработок.
- GTA 6 — первая проверка. Если сработает, движок, канал и опыт переносятся на другие игры (сайт, карта — см. этап 3 и `IDEAS.md`).

## Главный принцип

Бот полезен, только когда в нём есть реальные пункты, а они появляются после релиза, когда люди начинают играть. Поэтому:

- до релиза — готовим инфраструктуру и канал, бота не продвигаем;
- пик спроса — примерно с 3-го по 35-й день после релиза (люди собирают коллекционки);
- решения принимаем по `/stats`, а не по ощущениям;
- контент важнее интерфейса: красивое приложение с пустым списком никого не удержит.

## Как собираем контент

Владелец сам не играет (нет консоли), поэтому весь контент — из чужих гайдов и видео, со сверкой источников.

Источники по мере появления после релиза (по опыту прошлых больших игр):

1. **Первые часы — 3 день:** Reddit (r/GTA6), англоязычный YouTube, Discord-сообщества — сырые и неполные данные. Находки со стримов Twitch за несколько часов переезжают на YouTube и Reddit.
2. **3–10 день:** IGN, PowerPyx, GameRant, MapGenie, Fandom-вики — полные гайды.
3. **1–2 неделя:** русские сайты (Игромания, StopGame, VGTimes, Канобу), полные карты.
4. **Недели и месяцы:** настоящие секреты и пасхалки.

Инструменты:

- **«Радар»** (на ПК владельца) — следит за YouTube-каналами каждые 2 часа, разбирает субтитры через Devin CLI и присылает в Telegram находки с таймкодами и сигнал «можно собирать» (категория подтверждена 2+ каналами и есть полный список). Это один источник, не истина: в бота ничего не пишет. Сайты не смотрит — их закрывают сводки Devin по запросу.
- **Devin в чате** — по запросу: новости и текстовые гайды с сайтов, сборка категории, «что нового» в любой момент. Запланированных задач нет: без запроса ничего не происходит.

Порядок работы:

- категорию собирает Devin по запросу в чате: поиск, сверка минимум по 2 источникам (выгрузка `radar export <категория>` — один из них), черновик со ссылками на источники и пометками спорных пунктов — готовыми командами `/newcat` и `/add` (или YAML для `content/`);
- владелец проверяет и вносит пункты прямо из Telegram командами админа (`SPEC.md`), проверяет результат через `/cat`;
- тексты — своими словами; факты брать можно, копировать чужие списки и базы целиком нельзя (ст. 1334 ГК РФ — защита баз данных);
- подсказки от читателей в комментариях канала проверяются и вносятся вручную (краудсорсинга в боте нет).

## Канал и черновики

Схема — **полуавтомат**: Devin готовит по запросу, владелец одобряет.

- Сводка по запросу («сводка» в чате Devin; можно утром, примерно к 8:47 по Самаре, как раньше): новости по GTA 6, появившиеся гайды по коллекционкам, 1–3 черновика постов с источниками по навыку `tg-post-polny-zachet`, сигнал «какие категории уже можно заполнять». Автоматического расписания нет.
- Канал нужен в первую очередь для удержания (новая категория → повод вернуться в бота), привлечение — через пересылки полезных постов.
- Посты об обновлениях бота — по истории изменений (git log, `FIXES.md`), через Devin.
- Время владельца на канал: 10–15 минут в день на проверку, плюс 5–10 минут на сводки «Радара».
- Возможная доработка: кнопки «Опубликовать / Править / Отклонить» для черновиков прямо в Telegram — записана как идея, в v1 не входит.

## Сознательно не делаем

- **Полностью автономный агент для канала** — будет ошибаться в фактах и публиковать слухи, а доверие к каналу чек-листа держится на точности.
- **Парсер «по всему интернету»** — данные неструктурированы, лучшие источники запрещают парсинг. Вместо него — «Радар»: только выбранные YouTube-каналы, только субтитры, без скачивания видео.
- **Twitch как источник данных для бота** — стримы длинные, без структуры и субтитров. Для нарезок (`shorts-cutter`) стримы используются, для наполнения чек-листа — нет.
- **Свои видео и списки «первым»** — владелец не играет, поэтому не соревнуемся в скорости с теми, кто играет; берём точностью и удобством.
- **Нарезки чужих роликов без разрешения** — не делаем никогда (авторские права, Content ID, страйки).
- **Нативное мобильное приложение** — дорого, сторы, никто не ставит ради одной игры. Карта в перспективе — на сайте, открывается и в Mini App.
