# Задачи на разработку

Файл для Devin. Как работать:

- Бери первую задачу со статусом `[ ]`, делай только её.
- Не меняй поведение, которое задача не затрагивает. Требования SPEC.md остаются в силе.
- На каждую задачу — тест. После задачи прогони `pytest`, все тесты должны быть зелёными.
- Когда готово: поставь `[x]`, допиши под задачей строку `Сделано: <что изменено, какие файлы>`, остановись и покажи итог. К следующей задаче переходи только по команде.
- Принятые владельцем задачи удаляются из файла.
- Если задача противоречит SPEC.md или непонятна — не угадывай, спроси.
- Если задача меняет поведение, описанное в SPEC.md, — обнови соответствующий раздел SPEC.md в той же задаче.

Новые задачи добавляются в конец списка.
